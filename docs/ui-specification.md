## Summary of Architecture
- **22 Screens Covered** across 4 distinct user domains (Public, Customer, Technician, Admin).

- **WCAG 2.1 AA/AAA Verified** in both light (`#F5F7F8`) and dark (`#101E2C`) themes.
- **Component Architecture**: Atomic layered system with domain-specific organisms (RepairStatusStepper, WarrantyCoverageCard, TechnicianBenchSheet).
- **Navigation Guarding**: Strict role-based routing matrix with automated redirects and session hydration.
